# نظام التصميم

> الهوية مشتقة من لوجو محافظة الفيوم (`brand/fayoum-governorate-logo.png`): **الأخضر** هو اللون الأساسي، و**البرتقالي/الذهبي** للنقاط والتمييز، ومن اللوجو كمان الخط العربي المستدير وزخرفة **الساقية** (رمز الفيوم).
> القيم مأخوذة بالعين من صورة اللوجو. **لازم نطابقها مع دليل الهوية الرسمي للمحافظة** لو متاح.
> المصدر البرمجي الوحيد للقيم دي هو [`brand/tokens.json`](../brand/tokens.json)، ونسخة CSS منه في [`brand/tokens.css`](../brand/tokens.css).

---

## 1. المبادئ
1. **رسمي وموثوق:** ده نظام حكومي بيتاخد منه قرارات محاسبة. مفيش زخرفة زيادة، والوضوح أهم من الإبهار.
2. **من اليمين لليسار أولاً:** كل الواجهات بتتصمم بالعربي (RTL) الأول، والإنجليزي نسخة معكوسة.
3. **اللون معناه حالة:** ألوان الحالات والأولويات والأداء ثابتة في كل الشاشات والخرائط والتقارير، ودايماً معاها نص أو أيقونة (مش اللون لوحده).
4. **بسيط للمواطن:** تقديم البلاغ في **3 خطوات** بحد أقصى، وأزرار كبيرة، وأقل كتابة ممكنة.
5. **كثيف للغرفة:** لوحات الغرفة بتعرض بيانات كتير على شاشة واحدة، ومحسّنة للشاشات الكبيرة.

## 3. الخطوط
**الخط المعتمد: Readex Pro لكل حاجة.** عائلة واحدة بتغطي العربي والإنجليزي بتصميم متناسق، فمش محتاجين خط تاني للإنجليزي أو للأرقام.

| الاستخدام | الوزن |
|---|---|
| العناوين واللوجو | Bold 700 |
| العناوين الفرعية والأزرار | SemiBold 600 |
| التسميات والعناصر المحددة | Medium 500 |
| النصوص | Regular 400 |
| الأرقام في المؤشرات والجداول | 600–700 مع `font-variant-numeric: tabular-nums` |

- أقصى وزن في Readex Pro هو **700**، فمفيش وزن 800.
- الخط مجاني بترخيص OFL ومتاح على Google Fonts، ولازم نستضيفه **محلياً** في الإنتاج.
- الخطوط البديلة لو الخط محمّلش: `'Segoe UI', Tahoma, sans-serif`.
- صفحة المقارنة اللي اتعمل منها الاختيار: [`brand/font-options.html`](../brand/font-options.html).
**الأرقام:** عربية غربية (0123) في لوحات الغرفة والتقارير علشان الدقة، وقابلة للتبديل لأرقام مشرقية (٠١٢٣) في تطبيق المواطن.

## 4. المسافات والزوايا والظلال
- **المسافات:** شبكة 4px: `4, 8, 12, 16, 20, 24, 32, 40, 48, 64`.
- **الزوايا:** `sm 6px` (الحقول)، `md 10px` (الأزرار)، `lg 16px` (البطاقات)، `full` (الشارات). الزوايا المستديرة متناسقة مع انحناءات خط اللوجو.
- **الظلال:** `sm: 0 1px 2px rgb(22 33 26 / .06)`، `md: 0 4px 12px rgb(22 33 26 / .08)`، `lg: 0 12px 32px rgb(22 33 26 / .12)`.
- **أهداف اللمس:** 48×48 على الأقل في الموبايل.

## 5. المكوّنات الأساسية
| المكوّن | المواصفات |
|---|---|
| **الزر الأساسي** | خلفية `green-600`، نص أبيض، ارتفاع 48 (موبايل) / 40 (ويب)، زاوية `md` |
| **الزر الثانوي** | حدود `green-600`، نص `green-600`، خلفية شفافة |
| **زر الطوارئ** | خلفية `#DC2626`، أيقونة تحذير، بعرض الشاشة كاملاً في تطبيق المواطن |
| **شارة الحالة** | خلفية = لون الحالة بشفافية 12%، نص = لون الحالة داكن، أيقونة + نص |
| **بطاقة المؤشر (KPI)** | رقم `display`، اسم المؤشر `small muted`، سهم الاتجاه (↑ أخضر / ↓ أحمر حسب الأفضل)، خط بياني صغير لآخر 30 يوم |
| **بطاقة البلاغ** | صورة مصغرة، الكود، التصنيف، القرية، شارة الحالة، شارة الأولوية، الوقت المتبقي على مدة الحل |
| **عدّاد مدة الحل** | شريط تقدم: أخضر < 50%، كهرماني 50–100%، أحمر عند التجاوز + نص «متأخر 3 س» |
| **الخط الزمني** | عمودي، كل حدث بأيقونة الحالة ولونها، والفاعل والوقت. ده المستخدم في سجل التدقيق |
| **نافذة البلاغ على الخريطة** | الصورة، التصنيف، الحالة، زر «فتح التفاصيل» |
| **طبقات الخريطة** | لوحة جانبية: الأساس (OSM / أقمار صناعية)، النقاط (حسب الحالة / حسب الأولوية)، الخريطة الحرارية، أداء الوحدات |

## 6. الأيقونات
- مكتبة **Lucide** (مفتوحة المصدر، خط بعرض 2px يتناسق مع خط اللوجو).
- **أيقونات التصنيفات** (مخصصة بنفس الأسلوب): قمامة، صرف صحي، مياه، إنارة، طرق، تعدٍّ زراعي، بناء مخالف، أملاك دولة، مصارف، كلاب ضالة، تجريف، طوارئ.
- في واجهة RTL، الأيقونات الاتجاهية (الأسهم، رجوع) بتنعكس، وباقي الأيقونات لأ.

## 7. الشاشات المرجعية
| الشاشة | التخطيط |
|---|---|
| تطبيق المواطن: تقديم بلاغ | الخطوة 1: التصنيف (شبكة أيقونات) ← الخطوة 2: الصور والوصف ← الخطوة 3: تأكيد الموقع (خريطة + اسم القرية) ← إرسال |
| غرفة العمليات | الخريطة تملأ الشاشة، وفوقها شريط مؤشرات علوي، وعلى اليمين قائمة البلاغات اللحظية، وعلى اليسار الفلاتر والطبقات |
| لوحة المحافظ (موبايل) | 4 بطاقات مؤشرات ← الإنذارات ← ترتيب الوحدات (أسوأ 5 / أفضل 5) ← خريطة مصغرة |
| رئيس الوحدة | قائمة بلاغات (تبويبات حسب الحالة) + ترتيب الوحدة + زر إسناد |

## 8. الوضع الداكن
مطلوب للوحة الغرفة (شاشات بتشتغل طول اليوم) واختياري للتطبيقات. القيم في جدول المحايدات بالأعلى. ألوان الحالات بتفضل زي ما هي، والأخضر الأساسي بيبقى `green-400 #3FA765` للنصوص.

## 9. لوجو المنصة
- **المفهوم المعتمد:** **مكبّر صوت** أخضر يعني «صوتك وصل». ده الرمز المتعارف عليه للبلاغ والإعلان عن مشكلة. **الموجات الذهبية** بلون لوجو المحافظة ومعناها إن الصوت بيوصل للمسؤول. مكبّر الصوت متوجه **لليسار**، ناحية اتجاه القراءة العربي.
- الاتجاهات اللي اتعرضت قبل الاختيار موجودة في [`brand/logo-options.html`](../brand/logo-options.html).
- **الملفات:**
  - [`brand/ballegh-mark.svg`](../brand/ballegh-mark.svg): الرمز لوحده (أيقونة التطبيق، والـ favicon).
  - [`brand/ballegh-logo-horizontal.svg`](../brand/ballegh-logo-horizontal.svg): الرمز + الاسم.
  - [`brand/ballegh-app-icon.svg`](../brand/ballegh-app-icon.svg): أيقونة التطبيق على خلفية خضراء.
- **المسافة الآمنة:** حوالي نص عرض الرمز من كل الجهات. **أصغر حجم:** 24px للرمز.
- **ممنوع:** تغيير الألوان، أو مط اللوجو، أو وضعه على خلفيات مزدحمة.
- **في التقارير الرسمية:** لوجو المحافظة على اليمين، ولوجو المنصة على اليسار.
- ده **مقترح مبدئي**، ومحتاج مصمم يحوّل الاسم لخط مرسوم مخصص بدل الخط الجاهز.
