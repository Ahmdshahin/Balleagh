# القرارات والأسئلة المفتوحة

المصدر: `Questions and anwsers.docx`. الأرقام بين الأقواس هي أرقام الأسئلة.

## 1. قرارات معتمدة (مختصر)
| المحور | القرار |
|---|---|
| الجهة والعرض | ديوان عام المحافظة (1). عرض تقديمي + نموذج تجريبي (2). مفيش موعد محدد للعرض (3) |
| النطاق | قرى ومدن وأحياء (5). الوحدات المحلية بس، والمديريات لاحقاً (8) |
| الهوية | حساب أو جوجل أو مايكروسوفت + OTP إلزامي على الموبايل (11، 12). مفيش بلاغ مجهول (13) |
| اسم المنصة | **«بلّغ»** (Ballegh)، ومعاه السطر الوصفي «منصة بلاغات محافظة الفيوم» |
| الخط | **Readex Pro** لكل حاجة: العناوين والنصوص والأرقام، والعربي والإنجليزي |
| اللوجو | مكبّر صوت أخضر بموجات ذهبية |
| المنطقة التجريبية | **الوحدة المحلية ببني صالح وزاوية الكرادسة** (قريتين، مركز الفيوم) + **الوحدة المحلية بالسيليين** (مركز سنورس — مكتوبة «السلين» في التعداد، كود 230407). الإعداد pilotUnits |
| الحد اليومي | 5 بلاغات، والغرفة تقدر تغيّره (18) |
| الوسائط | 5 صور أو فيديو واحد 5 دقائق (22). مسموح من المعرض (23). علامة مائية (24) |
| الموقع | تلقائي مع تأكيد أو تعديل يدوي (25). القرية تتحدد تلقائياً (55) |
| بدون إنترنت | نعم (32) |
| اللغة | عربي + إنجليزي (35) |
| الأولوية | 4 مستويات (39)، بيحددها السيستم والغرفة تعدّل (33، 40، 45) |
| مدد الحل | تتظبط من الغرفة (41) |
| خارج النطاق | يروح للمحافظة (49) |
| الخريطة | OpenStreetMap + أقمار صناعية (51، 52) |
| التوجيه | تلقائي للوحدة (57). الوحدة ترفض بسبب، والغرفة تاخد عينة (58) |
| الحل | صورة في نفس الموقع + تقرير بحقول ثابتة ونص حر (59–61) |
| التصعيد | تلقائي (63). سجل تدقيق رسمي (67، 68) |
| الوحدة | حسابات فرعية للموظفين (69، 70). ويب + موبايل (71). مفيش رسائل مباشرة للمواطن (74) |
| الغرفة | مشرف + مراجع (82). لحظي بصوت (81). نقاط ملونة وخريطة حرارية وتلوين الوحدات (78، 79) |
| المؤشرات | للوحدة وللموظف (73). الوحدة تشوف ترتيبها بس (87). إنذارات واتجاهات (90، 91) |
| السوشيال | إدخال يدوي في المرحلة الأولى (93)، والرصد الآلي في مرحلة لاحقة (94) |
| التشغيل | استضافة داخل مصر (97). Geo-Scale (98). 1000 بلاغ/يوم (99). بيانات تجريبية حقيقية (100) |
