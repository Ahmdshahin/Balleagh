# الأدوار والصلاحيات

## الأدوار
| الكود | الدور | النطاق |
|---|---|---|
| `CITIZEN` | مواطن | بلاغاته فقط |
| `UNIT_STAFF` | موظف وحدة | البلاغات المسندة له |
| `UNIT_HEAD` | رئيس وحدة محلية | نطاق وحدته |
| `CENTER_HEAD` | رئيس مركز / مدينة | وحدات مركزه |
| `OPS_REVIEWER` | مراجع غرفة العمليات | المحافظة كلها |
| `OPS_SUPERVISOR` | مشرف غرفة العمليات | المحافظة كلها + الإعدادات |
| `GOVERNOR` | المحافظ (ومن يفوضه) | المحافظة كلها، قراءة |
| `SYS_ADMIN` | مدير النظام (الشركة المشغّلة) | تقني فقط، من غير اطلاع على البيانات الشخصية |

## قواعد مهمة
- **تغيير رئيس الوحدة:** الحساب مربوط **بالشخص** مش بالوحدة. عند النقل، المشرف يعطّل الحساب القديم ويعمل حساب جديد، والبلاغات المفتوحة تنتقل تلقائياً للرئيس الجديد. الأداء التاريخي يفضل محسوب للشخص الأول وللوحدة.
- حسابات الغرفة والمحافظ ورؤساء الوحدات لازم تفعّل المصادقة الثنائية.
- أي اطلاع على بيانات المبلّغ المخفية بيتسجل في سجل التدقيق.
